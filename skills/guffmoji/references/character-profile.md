# Character profile

Use this optional record alongside an approved character sheet when moving between chats or tools. Fill only what the source image and user establish. Leave unseen details unspecified, or label them as proposed design choices. The image remains the primary visual reference.

Copy this template for each character:

```yaml
name: ""
reference_sheet: "" # Filename or user-accessible link; attach the image too.
identity_anchors:
  face_shape: ""
  hair: ""
  glasses: ""
  facial_hair: ""
  headwear: ""
  outfit: ""
  shoes: ""
  accessories: ""
  silhouette: ""
expression_language:
  neutral: ""
  delight: ""
  panic: ""
  characteristic_gesture: ""
keep_consistent: []
user_approved_changes: []
design_choices_for_unseen_details: []
```

Record visible design details, not inferred personality, biography, or sensitive personal attributes. Distinguish a user-approved change from accidental drift. A character can change clothes without losing their identity.

## Example anchors

These summarize the demonstration sheets in the repository. Use the actual images when generating these characters; do not apply these features to someone else's avatar.

**Ricky:** forward baseball cap, round glasses, elongated face, prominent rounded nose, light facial stubble, rolled-sleeve button shirt, casual pants, large floppy sneakers. Exaggerated open mouth with blocky teeth and thin, expressive fingers.

**Partner:** voluminous curly hair with flyaway strands, a smaller and less prominent nose than Ricky's, pendant necklace, dark long-sleeved top, slim dark pants, chunky combat boots. Preserve the hair silhouette and pendant through motion and exaggerated expressions.
